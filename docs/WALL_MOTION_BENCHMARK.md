# Wall Motion 기술 벤치마킹 / REF-95

확인일: 2026-11-04. 공식 문서, 공개 실행 데모, 실제 Playground를 구분한다. 아래 값은 전체 Dynatrace 제품의 모든 컴포넌트에 동일하게 적용된다는 의미가 아니다.

| 공식 [Tabs Basic 데모](https://developer.dynatrace.com/docs/components-api/stable/use-cases/index.html#/navigation/tabs/Basic/stories)        | 탭 선택 후 panel은1개이며 선택된 콘텐츠로 교체됐다. 실행 예제의 tablist/tabpanel에서는 유효한 CSS transition/animation이 관찰되지 않았다                                                                                                                                                                                                                             | 모든 Strato Tabs가 항상 즉시 전환한다고 일반화하지 않는다                                                                                                                                                                             |

공식 데모 stable build의 정확한 패키지 버전은 노출된 정보만으로 확정하지 않았다. 문서 changelog 버전을 실행 번들의 버전으로 간주하지 않는다. CSS 측정과 inline DOM 높이 샘플은 직접 관찰이며, 위 미확인 항목은 추측으로 채우지 않는다.

## Wall에서 바꾼 구조

| 영역               | 이전 문제                                                                                                                                    | 적용 방식                                                                                                                                                                                                                                              |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Accordion          | height close190ms와 Chevron240ms가 달랐다. 높이용 easing이 초반에 빠르게 줄어드는 feedback 곡선이었다                                        | 열림/닫힘과 Chevron을 공통250ms/ExpandCollapse 곡선으로 통일했다. 실제 Base UI Collapsible의 측정 높이·중단·종료·keepMounted 계약은 유지한다. CSS와 JS height engine을 중복 실행하지 않는다                                                            |
| Dropdown / Popover | 닫힘 시 entry와 반대인 위치가 아닌0px로 되돌렸고, Command Menu는 fade가 끝나기 전에 Drill-in 내용을 초기화했다                               | entry170/exit150ms, 방향별3px translation과 opacity만 사용한다. 닫힘 중 pointer-events는none. 메뉴 path 초기화는 Base UI onOpenChangeComplete(false)로 옮겨 닫힘 중 재열기에서도 기존 내용이 유지된다. 완전히 닫힌 뒤 재열면 기본 메뉴다               |
| Secondary Rail     | width가224px인 첫 프레임부터 visibility hidden이었다. width/flex-basis를 동시에 전환하고 이전 단일 Sidebar의 display:none 규칙도 남아 있었다 | width만250ms, 내부는 고정223px 폭으로 유지해 텍스트를 다시 줄바꿈하지 않는다. 내용은150ms fade/열림50ms 지연, visibility는 폭 전환 종료 뒤 변경한다. 닫힘 시작부터 inert/aria-hidden으로 입력·접근성 노출을 제한한다. 오래된 즉시 숨김 규칙을 제거했다 |
| 탐색 컨텍스트      | 범위 전환 때 key로 subtree를 remount하고 opacity0.5부터 다시 재생했다                                                                        | 입력·목록 subtree를 유지하며 내용만 갱신한다. 메뉴를 빠르게 옮겨도 반복 fade/remount를 만들지 않는다. 검색/접힘/스크롤의 컨텍스트별 상태와 URL 동기화는 유지한다                                                                                       |

실제 import는 기존 local shadcn 방식 Button/Collapsible/Dropdown/Popover와 `@base-ui/react` primitive다. Motion for React, Strato 또는 Radix를 Wall에 추가하지 않았다. Wall 색상·폰트·레이아웃과 기존 Tabs180ms는 유지한다. 텍스트 scale, transition-all, Grid/Drag/Resize tween은 추가하지 않았다. reduced-motion의 본문/portal 전환 제거 규칙도 유지한다.

## 검증과 한계

- 공통 컴포넌트/Navigation/Inspector/PanelActions4 suites18 tests 통과. 입력·DOM identity·닫힌 rail inert·기존 메뉴 액션/권한을 확인했다. jsdom으로 실제 시간 곡선을 검증했다고 표현하지 않는다.
- 실제 Time series140에서 height0→4.375→20.922→…→391.781px와 다음 설정 제목의 동일한 이동을 관찰했다. 높이와 Chevron 모두250ms/같은 easing이다.6회 연속 반전, 입력1→2 변경 뒤4회 반전 후2 유지·취소를 확인했다. 원본은 저장하지 않았다.
- 스크롤한 Inspector에서 header top550px/scrollTop509를 유지하면서 높이892→647px로 접히는 것을 확인했다. 화면 밖 제목에 키보드 focus를 옮길 때 발생하는 native scroll-into-view는 제거하지 않았다.
- Light/Dark, 쿼리 옵션, 위로 flip된 메뉴의 +3px/아래 Popover의 −3px, 종료150ms 동안 Inspector 내용 유지·pointer none, 종료 중 재열기/종료 완료 후 초기화를 확인했다. 일반 종합 UID의 Gauge19 편집기에도 동일250ms가 적용됐다.
- 레일 축소에서222.516→217.938→…→6.375px 동안 visibility visible, 내부 브랜드 폭88.016px 고정, opacity0.723→0, inert true를 확인했다. 패널 편집 취소 직후의 첫 비교는 일부 좌표가 일치하지 않았고 원인은 이번 조사에서 확정하지 않았다. 안정된 화면에서 다시 기준을 잡은 레일 왕복 후25개 패널 DOM rect는 모두 동일/Dirty0이었다. 첫 비교의 차이를 해결했다고 표현하지 않으며 Grid 수정 범위로 확대하지 않았다.
- Grid 관련7개 파일 SHA-256, Grid/settle/layout 토큰과 Grid CSS block은 작업 전후 동일하다. 원본19개 Dashboard JSON 전체 동일. 상세 증거는 `/tmp/wall-motion95-preservation.json`이다.
- 실제 캡처는 `wall-motion-ref95/accordion-motion.gif`에 남겼다.16장의417ms 캡처를 GIF로 인코딩하고 끝에 보기용600ms 정지를 추가했다. 정밀 FPS/CPU 성능 프로파일이 아니며, 정적 테스트 수를 Dynatrace와 동일한 체감 품질의 점수로 표현하지 않는다. OS reduced-motion 설정은 변경하지 않았고 해당 CSS 분기와 portal 적용 범위를 확인했다.
